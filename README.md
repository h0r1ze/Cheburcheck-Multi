# Cheburcheck Multi

Пакетная проверка VPN-серверов (и любых доменов/IP) на блокировки в России через [cheburcheck.ru](https://cheburcheck.ru).

Вставляете ссылки на свои серверы — `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://` или просто IP/домен — и видите по каждому:

- есть ли адрес в реестре РКН и списках блокировок;
- стоит ли за ним CDN, ASN, страна;
- результаты проб от российских провайдеров в реальном времени: **ТСПУ-блок**, **SNI-блок**, **подмена DNS**, **обрыв CDN 16–20 КБ** или **доступен** — с разбивкой по операторам и регионам.

Работает на **Windows и Linux** (и macOS). Нужен только Python 3.8+, сторонних библиотек нет.

> Это неофициальный клиент. Все данные берутся из публичного API cheburcheck.ru — спасибо авторам [LowderPlay/cheburcheck](https://github.com/LowderPlay/cheburcheck).

## Возможности

- **Плитки-светофор** — цвет плитки = итоговый вердикт, всё видно за секунду. Клик по плитке — подробности и редактирование.
- **Выпадающий список серверов** в панели деталей; имя берётся из `#фрагмента` ссылки, можно переименовать.
- **Сколько угодно серверов** — «+ добавить адрес» / «Удалить».
- **Сохранить / Экспортировать / Импортировать** — список хранится в `state.json` рядом со скриптом (автосохранение тоже есть), экспорт в `.json`, импорт из `.json`, текстового списка ссылок или base64-подписки.
- **Учёт лимитов сайта** — cheburcheck.ru пускает 5 запусков проб в минуту с одного IP; приложение само ставит проверки в очередь и показывает это.
- **10 тем оформления** + «Авто» (тёмная/светлая по системе): Чебурчек, Светлая, Полночь, Терминал, Дракула, Норд, Соляризация, Груввокс, Сепия, Контраст.

## Запуск

Скачайте репозиторий (**Code → Download ZIP** или `git clone`), затем:

**Windows** — установите [Python 3](https://www.python.org/downloads/) (отметьте «Add python.exe to PATH») и запустите двойным кликом `start.bat`.

**Linux / macOS:**

```bash
./start.sh
```

Браузер откроется сам на `http://127.0.0.1:18765/`. Если порт занят, будет взят следующий свободный. Повторный запуск не создаёт вторую копию, а просто открывает вкладку с уже работающей. Остановить — `Ctrl+C` в окне консоли.

Параметры: `python3 cheburcheck.py --port 18765 --no-browser --host 127.0.0.1 --verbose`.

## Как это устроено

```
браузер (index.html)  ⇄  cheburcheck.py (локальный сервер на 127.0.0.1)  ⇄  cheburcheck.ru/api/v1
```

- `GET /api/v1/check?target=…` — проверка по спискам, геоданные, CDN.
- `GET /api/v1/probe/<id>` — SSE-поток результатов проб с узлов у российских провайдеров.

Браузер не может обращаться к API сайта напрямую (CORS), поэтому `cheburcheck.py` проксирует запросы, повторяет их при `429` (лимит) и хранит состояние в `state.json`. Итоговый вердикт по пробам считается так же, как на сайте (`selectProbeVerdict` из `frontend/src/lib/api/probe.ts` оригинального проекта).

Ограничения со стороны сайта:

- пробы не запускаются для подсетей, ASN и частных IP — для них есть только проверка по спискам;
- результаты проб кешируются сайтом на 3 часа, повторная проверка в этот период вернёт те же данные;
- API неофициальный и может измениться.

## Файлы

| Файл | Что это |
|---|---|
| `cheburcheck.py` | локальный сервер: отдаёт страницу, проксирует API, сохраняет `state.json` |
| `index.html` | весь интерфейс (HTML/CSS/JS в одном файле) |
| `start.bat`, `start.sh` | запуск на Windows и Linux/macOS |
| `mockups/variants.html` | демо шести вариантов интерфейса (с выдуманными данными) |
| `state.json` | ваш список серверов и результаты — создаётся при работе, **в git не попадает** |

## Формат экспорта

```json
{
  "app": "cheburcheck-multi",
  "version": 1,
  "servers": [
    { "name": "NL-1", "link": "vless://…@nl1.example.net:443#NL-1" }
  ]
}
```

Импорт понимает этот формат, `state.json`, JSON-массив ссылок, текст со ссылками по одной на строку (строки с `#` и `//` в начале пропускаются) и base64-подписку.
